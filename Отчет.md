# Задание 1. Методы

## Задача 6
### Текст задачи
Большая буква. `public boolean isUpperCase (char x)`. Возвращает true, если символ x — большая буква от 'A' до 'Z'. Пример: x='D' — true; x='q' — false.

### Алгоритм решения
Символы сравниваются как числа по коду. Проверяется, что x не меньше 'A' и не больше 'Z'.

## Задача 7
### Текст задачи
Диапазон. `public boolean isInRange (int a, int b, int num)`. Возвращает true, если num входит в диапазон между a и b (включая границы), причём заранее неизвестно, какая граница больше. Пример: a=5, b=1, num=3 — true; a=2, b=15, num=33 — false.

### Алгоритм решения
Через `Math.min` и `Math.max` находятся настоящие левая и правая границы, после чего проверяется, что num лежит между ними включительно.

## Задача 8
### Текст задачи
Делитель. `public boolean isDivisor (int a, int b)`. Возвращает true, если одно число делит другое нацело. Пример: a=3, b=6 — true; a=2, b=15 — false.

### Алгоритм решения
Проверяются два остатка от деления через ИЛИ: a % b == 0 или b % a == 0.

## Задача 9
### Текст задачи
Равенство. `public boolean isEqual(int a, int b, int c)`. Возвращает true, если все три числа равны. Пример: a=3, b=3, c=3 — true; a=2, b=15, c=2 — false.

### Алгоритм решения
Проверяется a == b и b == c одновременно (через И) — если оба верны, то и a == c.

## Задача 10
### Текст задачи
Многократный вызов. `public int lastNumSum(int a, int b)`. Считает сумму последних цифр двух чисел. С его помощью нужно последовательно сложить пять чисел, используя минимум переменных.

### Алгоритм решения
Метод берёт остаток от деления на 10 у обоих чисел и складывает их. В main заведена одна переменная, метод вызывается подряд четыре раза, и каждый раз результат становится первым аргументом следующего вызова.

# Задание 2. Условия

## Задача 6
### Текст задачи
Тройная сумма. `public boolean sum3 (int x, int y, int z)`. Возвращает true, если сумма двух из трёх чисел равна третьему. Пример: x=5, y=7, z=2 — true; x=8, y=-1, z=4 — false.

### Алгоритм решения
Проверяются все три варианта (x+y==z, x+z==y, y+z==x) через ИЛИ — какое число окажется суммой, заранее неизвестно.

## Задача 7
### Текст задачи
Двойная сумма. `public int sum2 (int x, int y)`. Возвращает x+y, но если сумма попадает в диапазон 10–19, возвращает 20. Пример: x=5, y=7 — 20; x=8, y=-1 — 7.

### Алгоритм решения
Сумма сохраняется в переменную, проверяется, входит ли она в диапазон 10–19, и в этом случае возвращается 20, иначе — сама сумма.

## Задача 8
### Текст задачи
Возраст. `public String age (int x)`. Возвращает число x и слово «год»/«года»/«лет» по правилам склонения (с исключениями 11–14). Пример: x=5 — "5 лет"; x=31 — "31 год"; x=44 — "44 года".

### Алгоритм решения
По последней цифре (остаток от деления на 10) выбирается форма слова, при этом числа 11–14 отдельно проверяются как исключения и всегда получают форму «лет».

## Задача 9
### Текст задачи
День недели. `public String day (int x)`. Возвращает название дня недели по числу от 1 до 7, иначе — «это не день недели». Используется switch. Пример: x=5 — «пятница».

### Алгоритм решения
Число сравнивается в switch с вариантами от 1 до 7, в каждой ветке стоит break. Если совпадений нет — срабатывает default.

## Задача 10
### Текст задачи
Вывод дней недели. `public void printDays (String x)`. Печатает переданный день и все следующие до конца недели. Если строка не день — «это не день недели». Используется switch.

### Алгоритм решения
Дни идут по порядку в switch без break во всех ветках, кроме последней, поэтому выполнение «проваливается» дальше и печатает все дни до воскресенья. Несовпадение обрабатывает default.

# Задание 3. Циклы

## Задача 6
### Текст задачи
Одинаковость. `public boolean equalNum (int x)`. Возвращает true, если все цифры числа одинаковы. Пример: x=1111 — true; x=1211 — false.

### Алгоритм решения
Последняя цифра запоминается как образец, дальше в цикле поочерёдно отбрасываются и сравниваются с ней остальные цифры. При первом несовпадении возвращается false.

## Задача 7
### Текст задачи
Квадрат. `public void square (int x)`. Выводит квадрат из символов '*' размером x на x.

### Алгоритм решения
Два вложенных цикла: внешний — x строк, внутренний в каждой строке печатает x звёздочек.

## Задача 8
### Текст задачи
Левый треугольник. `public void leftTriangle (int x)`. Выводит треугольник высотой x, где количество звёздочек в строке равно её номеру.

### Алгоритм решения
Внешний цикл идёт по строкам, внутренний печатает столько звёздочек, каков номер строки.

## Задача 9
### Текст задачи
Правый треугольник. `public void rightTriangle (int x)`. То же самое, но выровнено по правому краю — перед звёздочками нужны пробелы.

### Алгоритм решения
Добавлен ещё один внутренний цикл перед звёздочками, печатающий пробелы в количестве x минус номер строки.

## Задача 10
### Текст задачи
Угадайка. `public void guessGame()`. Генерирует число от 0 до 9 и предлагает угадать его, считая попытки, пока пользователь не угадает.

### Алгоритм решения
Число получается как `(int) (Math.random() * 10)`. Дальше в бесконечном цикле считывается ввод (с проверкой на число), считаются попытки, и при совпадении цикл прерывается через break с выводом результата.

# Задание 4. Массивы

## Задача 6
### Текст задачи
Реверс. `public void reverse (int[] arr)`. Меняет исходный массив на обратный. Пример: arr=[1,2,3,4,5] → [5,4,3,2,1].

### Алгоритм решения
Элементы меняются местами попарно с противоположных концов через временную переменную, цикл идёт только до середины массива.

## Задача 7
### Текст задачи
Возвратный реверс. `public int[] reverseBack (int[] arr)`. Возвращает новый массив в обратном порядке, не меняя исходный. Пример: [1,2,3,4,5] → [5,4,3,2,1].

### Алгоритм решения
Создаётся новый массив той же длины, и в цикле в него копируются элементы исходного с противоположного конца.

## Задача 8
### Текст задачи
Объединение. `public int[] concat (int[] arr1, int[] arr2)`. Возвращает новый массив: сначала arr1, затем arr2. Пример: [1,2,3] и [7,8,9] → [1,2,3,7,8,9].

### Алгоритм решения
Создаётся массив суммарной длины, первый цикл копирует arr1 в начало, второй — arr2 следом за ним.

## Задача 9
### Текст задачи
Все вхождения. `public int[] findAll (int[] arr, int x)`. Возвращает массив индексов всех вхождений x. Пример: arr=[1,2,3,8,2,2,9], x=2 → [1,4,5].

### Алгоритм решения
Массив проходится дважды: сначала считается количество совпадений для длины результата, затем найденные индексы записываются в новый массив по порядку.

## Задача 10
### Текст задачи
Удалить негатив. `public int[] deleteNegative (int[] arr)`. Возвращает массив без отрицательных элементов. Пример: [1,2,-3,4,-2,2,-5] → [1,2,4,2].

### Алгоритм решения
Массив проходится дважды: сначала считается число неотрицательных элементов, затем они копируются в новый массив нужной длины.
